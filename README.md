# Яки Суприм

Адаптивный сайт японской кухни: анимированная рыбка и круги на воде, каталог из десяти блюд, избранное, поиск и демонстрационный заказ.

## Запуск

Сайт работает без сборки и сторонних JavaScript-зависимостей. Опубликуйте содержимое `dist/` на любом статическом хостинге.

Для локального просмотра из корня проекта:

```sh
python -m http.server 8080 --directory dist
```

Откройте http://localhost:8080/yaki-supreme/.

## Структура

- `dist/yaki-supreme/index.html` — главная, каталог и заказ.
- `dist/yaki-supreme/app.js` — интерактивное меню и корзина.
- `dist/yaki-supreme/pond.js` — анимация рыбки и воды.
- `dist/yaki-supreme/style.css`, `dist/yaki-supreme/cards.css` — оформление и адаптивная верстка.
- `dist/yaki-supreme/assets/` — изображения блюд и логотип.
- `IMAGE-PROMPTS.md` — промпты сгенерированных изображений меню.
- `.openai/hosting.json` — конфигурация существующей публикации Sites.

Заказ демонстрационный: данные формы никуда не отправляются, реальная оплата и доставка не подключены. Корзина и избранное хранятся в браузере. Изображения блюд созданы с помощью генератора изображений.
